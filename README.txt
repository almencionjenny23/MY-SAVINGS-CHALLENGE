# My Savings Challenge Hub — Website + App

## GitHub Pages
1. Upload **all 5 files** in this folder to the same GitHub repository folder:
   - index.html
   - manifest.json
   - service-worker.js
   - icon-192.png
   - icon-512.png
2. Make sure the main page is named **index.html**.
3. Enable GitHub Pages from the repository Settings → Pages.
4. Open the HTTPS GitHub Pages address.

## Netlify
Drag this folder into Netlify Drop, or upload the folder/repository.

## Install as an app
- **Android/Chrome:** open the website and tap Install App, or use the browser menu → Install app/Add to Home screen.
- **iPhone/iPad:** open in Safari → Share → Add to Home Screen.
- **Desktop Chrome/Edge:** use the browser's install icon/menu when available.

Your savings data continues to use the app's existing browser storage. The PWA shell also caches the main site so it can reopen offline after the first successful visit.
